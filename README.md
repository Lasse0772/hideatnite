# Hide @ Nite

> **⚠️ Note:** This is the English branch of Hide @ Nite. The English version has not been built yet — we are currently still working on the German version. Once that is stable and fully tested, the English version will follow.
>
> In the meantime, feel free to check out the German main branch: [main](../../tree/main)

---

GPS-based bicycle hide-and-seek as a PWA. Create a lobby, invite friends with a code, and ride.

## Features

- 🚲 Two game modes: Elimination & Infection
- 📍 Real-time GPS on OpenStreetMap
- 🔄 Shrinking & wandering zone (Fortnite-style)
- 📡 Periodic location pings for all players
- 🤚 Catch flow with double confirmation
- ⚙️ Fully customizable lobby settings
- 📱 PWA — installable like an app, no app store needed

## Stack

React + Tailwind · Leaflet.js + OpenStreetMap · FastAPI · WebSockets · Docker
